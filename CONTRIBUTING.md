# Contributing

Welcome: documentation, tests, security fixes, pagination correctness, coverage diagnostics, data quality, and agent ergonomics.

Tests must not use real X credentials or live scraping. Before a pull request, run pytest and ruff. Never include cookies, account databases, HAR exports, private data or server secrets in issues or commits.

Research reports should include source URLs and honestly identify partial results. Avoid features to evade restrictions, rotate identities against rate limits, or automate account engagement.
