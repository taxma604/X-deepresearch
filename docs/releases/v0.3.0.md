# X-deepresearch v0.3.0 — Initial GitHub Release

**A research-first, read-only MCP server for X conversations.**

Ask an MCP-enabled AI assistant to collect posts, track observed daily discussion volume, compare research jobs, and export results. Built for local use with the user's own X session.

## Highlights

- **Read-only research:** search posts, fetch user profiles and timelines, and retrieve individual posts.
- **Daily trends:** record observed post counts by **Japan Standard Time (JST)**, with research jobs spanning up to **90 calendar days**.
- **Long-running jobs:** check job progress, summarize peaks and totals, compare matching date ranges, and export **CSV, JSON or Markdown**.
- **Coverage information:** expose incomplete ranges and pagination issues instead of silently presenting incomplete data as exhaustive.
- **Local-first:** interactive hidden cookie entry, locally stored settings, restricted search options and optional SQLite recovery.
- **MCP clients:** one-command Codex CLI registration; setup guides for Claude Code, Claude Desktop, Cursor and VS Code.
- **Docs:** English and Japanese README and installation guides.

## Install

Requirements: Python 3.12+, Git, [uv](https://docs.astral.sh/uv/getting-started/installation/) and an X browser session you are authorized to use.

```bash
uvx --from git+https://github.com/taxma604/X-deepresearch@v0.3.0 x-deepresearch-setup
```

The command prompts for your **own** `auth_token` and `ct0`; it does not accept credentials on the command line. Codex CLI is required for the default automatic registration. For other MCP clients, add `--client none`, then follow the client-specific guide.

## Scope and limitations

- The server does **not** post, like, follow, send DMs or include automated sentiment analysis.
- Observed counts and coverage indicators are **not a guarantee** that every X post was retrieved.
- Authenticated Windows/WSL testing covered installation, ten MCP tools, small-range counting, comparisons, exports and optional SQLite recovery. The full 90-day range and other MCP clients have not been end-to-end validated.
- Access uses the third-party [Twikit](https://github.com/d60/twikit) integration and your own session. This project is independent of X; see [platform terms and limitations](https://github.com/taxma604/X-deepresearch/blob/v0.3.0/DISCLAIMER.md).
