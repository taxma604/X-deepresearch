# X-deepresearch v0.3.0 初回GitHubリリース

**Xの投稿をAIで検索・集計・比較する、読み取り専用のMCPサーバー。**

AIエージェントからX投稿を調べ、話題の日別推移や複数の調査結果を比較できます。取得したデータはCSV・JSON・Markdownで出力できます。

## 主な機能

- 投稿の検索、ユーザープロフィール・タイムライン、個別投稿の取得
- 日本時間で最大90日間の日別投稿数を集計
- 長時間かかる調査の進捗確認、要約、期間をそろえた比較
- 取得漏れやページ取得時の問題を確認する機能
- Cookieの非表示入力とPC内への保存、検索対象の制限、SQLiteによる任意の復元
- Codex CLIへの自動登録、Claude Code・Claude Desktop・Cursor・VS Code向け設定手順

## インストール

Python 3.12以降、Git、[uv](https://docs.astral.sh/uv/getting-started/installation/) と、自分のXセッションが必要です。

```bash
uvx --from git+https://github.com/taxma604/X-deepresearch@v0.3.0 x-deepresearch-setup
```

初期設定では自分の `auth_token` と `ct0` を非表示で入力します。値をコマンド引数に含める必要はありません。Codex以外のMCPクライアントでは `--client none` を追加し、対応する設定手順を参照してください。

## 制約

- 投稿、いいね、フォロー、DM送信や自動感情分析には対応していません。
- 取得件数はXの全投稿を保証するものではありません。
- Windows／WSLで主要機能の実機検証を行いましたが、90日間すべての調査やCodex以外のクライアントは未検証です。
- Xとの通信には[Twikit](https://github.com/d60/twikit)を使用します。X公式ツールではありません。利用上の条件については[補足資料](https://github.com/taxma604/X-deepresearch/blob/v0.3.0/DISCLAIMER.md)を確認してください。
